## Project
BlueLib Catalogue is a responsive single-page library catalogue built with:
- HTML5 semantic markup
- CSS3 with CSS custom properties, Grid and responsive media queries
- Vanilla JavaScript for DOM manipulation and events

## Features
1. Six initial books stored in a JavaScript array.
2. Dynamic book-card rendering.
3. Live title search.
4. Category filtering.
5. Add Book form without page reload.
6. Form validation for required fields and whole-number copies.
7. Borrow button that decreases available copies.
8. Borrow button becomes disabled and displays "Out of stock" at zero copies.
9. Responsive layout: 3 cards on desktop, 2 on tablet and 1 below 600px.
10. Hover effects on cards and buttons.

## How to run

1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. For the easiest development workflow, install/use the VS Code Live Server extension and choose "Open with Live Server" on `index.html`.

No npm install or React setup is required because the assignment explicitly requires plain HTML, CSS and vanilla JavaScript.
